
# 🚇 Система управления метрополитеном

## 📌 О проекте

Проект представляет собой комплексную систему управления метрополитеном, реализованную на базе PostgreSQL. Система позволяет эффективно управлять инфраструктурой метро, включая линии, станции, поезда и их расписание.

### Основные возможности:
- 📊 Централизованное хранение информации о структуре метрополитена
- 🕒 Управление расписанием движения поездов
- ⏱️ Расчет времени пути между любыми станциями
- 🔍 Поиск ближайших поездов для пассажиров
- 📈 Аналитика пассажиропотока и загруженности станций

## 🗃️ Модели данных

### 🖼️ Концептуальная модель

**Ключевые сущности:**
- `Lines` - линии метро с атрибутами (цвет, название)
- `Stations` - станции с указанием порядка на линии
- `Trains` - подвижной состав с направлением движения
- `Schedules` - детальное расписание движения
- `Segments` - перегоны между станциями с временем проезда
- `Transitions` - переходы между линиями с временем пересадки

### 📐 Логическая модель

**Особенности:**
- Приведена к **3NF** (третьей нормальной форме)
- Устранены все транзитивные зависимости
- Реализовано версионирование названий станций

**Версионирование (SCD Type 2):**
Таблица `Station_history` реализует Slowly Changing Dimension тип 2, что позволяет:
- Сохранять полную историю изменений названий
- Точное определение периода действия каждого названия
- Восстановление состояния системы на любую дату
- Анализ изменений названий во времени

### 💾 Физическая модель

**Характеристики:**
- Оптимальные типы данных для всех атрибутов
- Полный набор ограничений целостности:
  - Первичные и внешние ключи
  - Проверочные ограничения (CHECK)
- Специальный ENUM тип для направления движения
- Стратегически размещенные индексы

## ⚙️ Реализация

### 📊 Основные таблицы

| Таблица | Описание | Ключевые атрибуты |
|---------|----------|-------------------|
| `Lines` | Линии метро | line_id, line_name, color |
| `Stations` | Станции | station_id, line_id, station_name, order_on_line |
| `Trains` | Поезда | train_id, line_id, direction |
| `Schedules` | Расписание | schedule_id, train_id, station_id, arrival_time |
| `Segments` | Перегоны | segment_id, from_station_id, to_station_id, train_travel_time |
| `Transitions` | Переходы | transition_id, from_station_id, to_station_id, walk_time |
| `Station_history` | История станций | history_id, station_id, old_station_name, valid_from, valid_to |

### 🚀 Индексы

1. **`idx_schedules_station_id_arrival_time`**
   - Ускоряет поиск расписания по станции и времени прибытия
   - Критически важен для быстрого поиска ближайших поездов

2. **`idx_station_name_pattern`**
   - Оптимизирует поиск станций по части названия
   - Использует varchar_pattern_ops для эффективного поиска по шаблону

### ⚡ Триггеры

| Триггер | Назначение | Логика работы |
|---------|------------|---------------|
| `station_order_unique` | Контроль порядка станций | Поддерживает уникальность порядка станций на линии |
| `validate_transition_time` | Валидация переходов | Проверяет корректность времени перехода (1-15 мин) |

### 👁️ Представления

#### `station_schedule_with_transfers`
Объединяет расписание поездов с информацией о пересадках.

- Показывает возможные маршруты, включая пересадки между станциями разных линий.
- Включает время перехода (walk_time) из таблицы Transitions.
- Содержит данные о времени прибытия и отправления поездов из таблицы Schedule, а также информацию о станциях и линиях из Stations и Lines. 

#### `line_statistics`
Агрегированная статистика по линиям метро:

- Количество станций: Число станций на линии (из таблицы Stations, группировка по line_id).
- Количество поездов: Число записей в таблице Schedule для каждой линии (по train_id и line_id).
- Общее время проезда: Сумма времени движения между станциями (train_travel_time из Segments) плюс время стоянки (2 минуты на станцию, кроме последней).
- Количество пересадок: Число уникальных переходов (transition_id из Transitions), где начальная станция принадлежит линии.
